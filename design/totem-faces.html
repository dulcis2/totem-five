Five Totems · Carved Creatures

Twenty-five faces for the totem pole

Each colour is one animal with a fixed set of shared features, so its five faces read as one family. The faces vary only inside those features. The deck has 10 copies of each colour, so each face appears on two cards.

Your totem

Tap a colour to put a random face of that colour on top. Wings crown whichever card is on top.

Putting it in the game

Card ids are already shatter-1 … shatter-10, so the face is (n − 1) % 5 and needs no new game state. The art replaces the circle-and-glyph in CardView.tsx; the table stack in styles.css raises each card by 34% of the card height instead of shifting it down 16px.
